# Asset Name

godotnvim

# Asset Summary (max 500)

Godot Neovim replaces Godot's script editor with an embedded Neovim, keeping drag-and-drop, LSP, breakpoints, signal icons, editor colors and run shortcuts, and adds format on save, project-wide function search and session restore.

# Detailed Description (max 20000)

A Godot 4 editor plugin that edits GDScript, shaders and other text files in
an embedded Neovim, drawn inside the editor with Neovim's UI protocol
(`ext_linegrid`). It keeps the parts of Godot's script editor that matter:

- dragging nodes, files or Inspector properties into Neovim inserts the same
  text Godot does;
- the GDScript language server gives hover docs, definitions and completion;
- debugger breakpoints show in the gutter, in sync with Godot's debugger;
- signs mark methods that signals connect to and methods that override a base
  class;
- Neovim takes its colors from the script editor's theme;
- Godot's run, pause and stop shortcuts keep working while you type;
- `:GodotRunFile` runs an `EditorScript`, like the script editor's File → Run.

And adds what Godot's script editor doesn't have:

- **Format on save** with GDQuest's `gdscript-formatter` or gdtoolkit's
  `gdformat`, whichever is installed. `:GodotFormat` formats on demand.
- **`:GodotFunc <name>`** jumps to a function anywhere in the project, with
  name completion. Godot's language server has no project-wide symbol search.
- **Project → Tools → Create Neovim Editor Profiles** makes copies of your
  editor feature profiles with the Script tab hidden, so Neovim is the only
  script editor.
- **Session restore**: open files, cursor positions, splits and tabs come back
  when the project reopens.

Your Neovim config, plugins and keymaps load as usual.

The repository also has vim2godot, a separate command-line tool (prebuilt in
each GitHub release) that turns any Vim or Neovim colorscheme into a Godot
editor theme.

![Neovim tab with breakpoint, override and signal signs in the editor's colors](https://raw.githubusercontent.com/gdey/godotnvim/main/docs/screenshots/overview.png)

## Requirements

- **Godot 4.5 or newer.** The tests pass on 4.5.1, 4.6.1 and 4.7.1. On 4.4
  the editor can be killed by `SIGPIPE` when Neovim stops, and 4.3 lacks
  APIs the plugin uses.
- **Neovim 0.11 or newer**, installed separately.
- **Optional:** `gdscript-formatter` or `gdformat` for format on save.
- **Platforms:** Linux is tested. macOS is in daily use. Windows should work
  but is untested; reports welcome.
