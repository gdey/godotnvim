Install

  1. Install Neovim 0.9 or newer; 0.11+ is recommended for its default LSP mappings.
  2. Get the plugin from the Asset Library (search for "Neovim Script Editor"), or download godot_nvim-<version>.zip from the latest release and copy addons/godot_nvim into your project's addons/ folder.
  3. Enable Neovim Script Editor under Project → Project Settings → Plugins. A Neovim tab appears next to 2D / 3D / Script.
  4. Optional: run Project → Tools → Create Neovim Editor Profiles to hide Godot's Script tab.

The docs cover settings, the debugger, colors, formatting and the known gaps. The changelog lists what each release added.

Colors both ways

Neovim takes its colors from the script editor's theme and follows it when you change it. vim2godot goes the other way: it turns any Vim or Neovim colorscheme into a Godot editor theme, and each release has binaries for Linux, macOS and Windows.
