Install

  1. Install Neovim 0.10 or newer; 0.11+ is recommended for its default LSP mappings.
  2. Get the plugin from the Asset Library (search for "Neovim Script Editor"), or download godot_nvim-<version>.zip from the latest release and copy addons/godot_nvim into your project's addons/ folder.
  3. Enable Neovim Script Editor under Project → Project Settings → Plugins. A Neovim tab appears next to 2D / 3D / Script.
  4. Optional: run Project → Tools → Create Neovim Editor Profiles to hide Godot's Script tab.

The docs cover settings, the debugger, colors, formatting and the known gaps. The changelog lists what each release added.

vim2godot: any Vim colorscheme as a Godot theme

A command-line tool that turns a Vim or Neovim colorscheme, such as any on vimcolorschemes.com, into a Godot 4.5+ editor theme: the script editor's colors and the interface around them. It doesn't need the plugin, but with it, Neovim follows the new theme too.

Convert, install, done

Give it a vimcolorschemes.com page, a GitHub repository or a local folder. Each scheme becomes a .tet with the script editor's colors and an apply_<name>.gd that sets the interface colors. Schemes with dark and light variants are written as both.

vim2godot https://vimcolorschemes.com/r/aejkatappaja/cendre

# only tokyonight's storm style, installed straight into Godot
vim2godot -scheme tokyonight-storm -install folke/tokyonight.nvim

Then run apply_<name>.gd with File → Run in Godot's script editor. The vim2godot docs cover every flag and how the colors map.

It runs the colorscheme's code in a headless Neovim, so only convert schemes you would load in your own editor. On macOS the binary isn't signed; if Gatekeeper blocks it, run xattr -d com.apple.quarantine vim2godot.
